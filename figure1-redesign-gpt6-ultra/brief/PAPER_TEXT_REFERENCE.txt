BEYOND MEAN FOILS: AUDITING WORST-FOIL SPECIFICITY IN FROZEN CLIP REGION
EXPLANATIONS
Kaixin Liu, Zhipeng Ye, Feng Jiang, Qiufeng Wang, Jinye Li

ABSTRACT
A frozen CLIP region explanation can be spatially plausible while a non-target semantic foil responds more strongly than the target. We audit this failure with matched prompt-mean and aggregate worst-foil margins and evaluate the actual target-only CCI selector. On COCO/OpenAI B/16, the normalized aggregate margin is -.342 and 74.0% of selected regions have negative margin; hardest-foil identity has 59.8% mean pairwise agreement across held-out prompt families. We then test whether the failure is locally repairable inside the frozen CCI candidate set. A selection-stage target-tolerant reranking changes only 2.0-2.6% of regions at epsilon=.02 yet improves normalized aggregate worst-foil margin by .0150/.0108/.0118/.0087 on COCO B/16, COCO B/32, VOC B/16, and VOC B/32; 10,000-resample paired confidence intervals are above zero in all four, while held-out target-response intervals include zero. Gains persist when selection and evaluation use disjoint category foils and when evaluation is restricted to annotation-absent foils. Random and target-only feasible reranking do not explain the effect. Thus worst-foil debt is sparse but reproducible and locally repairable within frozen CCI candidates, without claiming a universally superior explanation rule.

METHODS - CORE DEFINITIONS
For checkpoint m, let s_m(x,c) be its fixed pre-activation scaled image-text similarity. For candidate region R and concept prompt c,

d_R(c) = s_m(x,c) - s_m(I(x,R),c).                                      (1)

Original target-only CCI selects

R_CCI = arg max_{R in R(x)} d_R^sel(t).                                  (2)

Matched held-out estimands normalize each class identically and define prompt-mean and aggregate worst-foil margins. P_max is ontology-relative, not human semantic ground truth or a stand-alone explanation quality score.

Selection-stage target tolerance:

M^sel(R,t) = d_R^sel(t) - max_{f in F_t} d_R^sel(f).                       (4)

R_epsilon = {R : d_R^sel(t) >= d_R_CCI^sel(t) - epsilon}.                 (5)

R_WF(epsilon) = arg max_{R in R_epsilon} M^sel(R,t).                      (6)

Equation 6 reads only selection-stage tensors; held-out prompts are used only after the region is fixed. epsilon=.02 is a small fixed operating point, not an optimized value. The method is not called target-preserving because the constraint is guaranteed only at selection stage; held-out target response is evaluated statistically.

PROTOCOL
K=8 frozen CCI regions on COCO val2014 (27,708 eligible images) and VOC2007 test (1,943), with OpenAI CLIP B/16 and B/32. The main intervention blocks selected patch key/value columns in every visual-transformer block and head, retaining the prefix token. Bbox precision is the fraction of selected patch centers falling inside any resize/crop-transformed target box. Main intervals use 10,000 paired unique-image bootstrap resamples (seed 1701). Cross-foil controls use ten fixed seeds and complementary category folds, pooling both selection/evaluation directions.

QUALITATIVE ENDPOINT SEPARATION
The paper's Figure 2 shows deterministic COCO/OpenAI B/16 examples at epsilon=.02. The examples make non-dominance explicit: one case improves both specificity and locality; another improves specificity while bbox precision falls; a counterexample worsens specificity even though locality rises. Thus reranking is not a per-image dominance rule.

CONCLUSION
Actual CCI can carry substantial ontology-relative worst-foil debt, and the effect survives matched estimands, disjoint/annotation-absent foils, matched foil counts, and 10,000-resample uncertainty checks. Arbitrary feasible reranking does not reproduce the gain. Worst-foil debt is a stable, locally repairable failure mode for a small subset of frozen CCI candidates, while target response and spatial locality remain separate endpoints.
